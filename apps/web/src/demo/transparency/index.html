Reproduction details

This uses real MineRenderWorld placement with sectionMeshing: true. The comparison shifts the panels and camera together by 15 blocks, putting the panels on opposite sides of a section boundary. Geometry, textures, spacing, and materials stay the same.

Generated textures have alpha 128/255 with opaque letters and borders. All assets stay local. The floor grid provides depth context. This comparison demonstrates this two-panel case; it does not establish general correctness across section boundaries.
