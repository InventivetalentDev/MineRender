World source

Procedural terrain with no world download.

World files stay in your browser. Block models and textures load from the asset CDN. Choose the version used by your world.

View center

Click the view to capture the mouse; Esc releases it. W/A/S/D move, space rises, shift descends, control sprints, and the wheel changes the speed. On touch screens the left half is a joystick and the right half looks around.

Chunks unload beyond the load radius plus one. Opaque terrain uses section meshes. Larger radii need more time and memory.

Supported worlds

Java Edition 1.13+ region files. Select a world folder to choose the Overworld, Nether, End, or a custom dimension. Files selected without folders are treated as one dimension.

Lighting, biome colors, entities, pre-1.13 numeric blocks, LZ4 compression, and external .mcc chunks are not rendered. This viewer streams existing chunks; it does not generate missing terrain.
